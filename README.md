# Le Comptoir · versions

Ce dépôt ne contient que les versions compilées du Comptoir, le back-office des boutiques
d'Emile. Le code source est privé.

L'appli installée y cherche ses mises à jour (`latest.json` de la dernière version) et n'accepte
que des versions signées avec la clé de son auteur.

Rien ici ne permet d'accéder à une boutique : l'appli ne fonctionne qu'avec un compte admin
de la boutique à laquelle on la connecte.
